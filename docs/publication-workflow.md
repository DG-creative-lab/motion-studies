# From technique to lesson

Keep one versioned study as the technical source. An AI Knowledge Hub article explains its purpose and trade-offs; a Visual Learning Studio video brief supplies the story, demonstrations and platform-specific edit. Record the public study version in both.

An optional agent skill should specify when to use the technique, required Remotion dependencies, frame/fps rules, editable parameters, verification commands and failure cases. Bundle only public code and neutral assets. Validate the skill on a clean example before calling it released.

First release includes timing code, tests and a frame scrubber. Remotion adapters, video productions and installable skills are future work. Do not claim a rendered video, shader or plugin extension exists merely because a brief describes it.
