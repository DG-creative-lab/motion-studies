# Motion studies

Small, reusable motion techniques from DG Creative Lab. These studies connect implementation lessons with future AI Knowledge Hub articles and Visual Learning Studio videos. The private production workshop and its brand artwork are not distributed here.

## Available now

[001 — Frame-driven loops](studies/001-frame-driven-loops/README.md): a dependency-free timing helper, runnable tests, and an interactive browser preview.

```sh
node --test
```

Use Node.js 22.18+ (or a newer supported LTS). To see the preview, run `python3 -m http.server 8080` from this directory and open http://localhost:8080/studies/001-frame-driven-loops/demo.html. No npm install is needed.

## Planned studies

- Local pattern deformation with protected reading zones.
- Objects coordinated through a shared motion field.
- Render-based loop seam and registration checks.
- Agent skills that apply and verify the techniques.

These are plans, not released features. See [publication workflow](docs/publication-workflow.md). This project is independent of, and does not modify, the installed Remotion plugin.
